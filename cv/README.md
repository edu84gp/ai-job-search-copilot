# CV — carpeta local

Esta carpeta permanece fuera del repositorio público por privacidad. Contiene las versiones del CV en revisión y, en `cv/cartas/`, las cartas de presentación generadas para ofertas concretas.

- Las versiones base y optimizadas del CV se gestionan en local.
- Las cartas se redactan con el agente `cover-letter-drafter` y se guardan en `cv/cartas/` con nombres `kebab-case`.
- El repositorio público solo conserva este README como referencia de estructura.
