# CV — carpeta local

Esta carpeta permanece fuera del repositorio público por privacidad. Contiene las versiones del CV en revisión, las cartas de presentación generadas para ofertas concretas y los certificados acreditativos.

- Las versiones base y optimizadas del CV se gestionan en local.
- Las cartas se redactan con el agente `cover-letter-drafter` y se guardan en `cv/cartas/` con nombres `kebab-case`.
- Los certificados se guardan en `cv/certificados/` con el patrón `entidad-nivel-anyo.pdf`, por ejemplo `ef-set-b1-2026.pdf`.
- El repositorio público solo conserva este README como referencia de estructura.
