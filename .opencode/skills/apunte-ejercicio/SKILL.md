# Apuntes y registros de ejercicios

## Estructura obligatoria

Todo registro de ejercicio incluye estas secciones en este orden:

1. Objetivo
2. Conceptos clave
3. Enfoque planteado
4. Estado de resolución

## Convenciones

- Archivos en kebab-case dentro de `docs/apuntes/` o `docs/ejercicios/`.
- El índice de ejercicios vive en `docs/ejercicios/indice-ejercicios.md` y se actualiza con cada registro.
- No incluir la solución completa salvo petición explícita de la persona.
- No incluir comentarios dentro de bloques de código.

## Reparto de agentes

- course-exercise-solver: guía el ejercicio y define los conceptos clave y el enfoque.
- tracker-doc: redacta y guarda el apunte o el registro.
- live-coding-coach e interview-coach: prácticas de código y entrevista relacionadas.
